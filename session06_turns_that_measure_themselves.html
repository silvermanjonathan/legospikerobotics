Chunk 1 of 3

The hub counts its own turn

Inside the hub is a motion sensor. It measures how far the hub has turned since the count was last set to 0. It counts in tenths of a degree of the robot's turn, so a quarter turn, which is 90 degrees of the robot's turn, counts as about 900.

Line 6 sets the count to 0. Line 7 waits 5000 thousandths of a second, which is 5 seconds. Line 8 prints the count. The [0] picks the first of three numbers the sensor gives. Type it exactly.

from hub import motion_sensor
import runloop


async def main():
    motion_sensor.reset_yaw(0)
    await runloop.sleep_ms(5000)
    print(motion_sensor.tilt_angles()[0])


runloop.run(main())

What the page works out

Computed, not measured

the sensor counts in tenths: 90 x 10 = 900

900, or close to it. The robot turned about 90 degrees of the robot's turn, and the sensor counts each one as 10.

Turning one way gives a minus sign and turning the other way does not. Run it twice, once turning right and once turning left, and write both numbers in the sheet.

Chunk 2 of 3

Turn until the count says a quarter turn

This is start, wait, stop again, with a new test. Line 13 sets the count to 0, and line 14 waits a tenth of a second for the sensor to settle. Line 15 starts a turn to the right on the spot.

Line 16 waits until the count is greater than QUARTER. abs takes away a minus sign, so the test works whichever way the sensor counts. Line 17 stops the wheels.

from hub import motion_sensor, port
import motor_pair
import runloop

QUARTER = 900


async def main():
    # The left drive motor is in port A. The right drive motor is in port E.
    motor_pair.pair(motor_pair.PAIR_1, port.A, port.E)

    # Set the count to 0. Turn right until the count passes QUARTER. Stop.
    motion_sensor.reset_yaw(0)
    await runloop.sleep_ms(100)
    motor_pair.move(motor_pair.PAIR_1, 100, velocity=250)
    await runloop.until(lambda: abs(motion_sensor.tilt_angles()[0]) > QUARTER)
    motor_pair.stop(motor_pair.PAIR_1)


runloop.run(main())

Question: A team wants a half turn, which is 180 degrees of the robot's turn. Before any testing, what first try should they give QUARTER? And is the name still a good one?

from hub import motion_sensor, port
import motor_pair
import runloop

FORWARD = 720
QUARTER = 900


async def main():
    # The left drive motor is in port A. The right drive motor is in port E.
    motor_pair.pair(motor_pair.PAIR_1, port.A, port.E)

    for count in range(4):
        await motor_pair.move_for_degrees(motor_pair.PAIR_1, FORWARD, 0, velocity=250)
        motion_sensor.reset_yaw(0)
        await runloop.sleep_ms(100)
        motor_pair.move(motor_pair.PAIR_1, 100, velocity=100)
        await runloop.until(lambda: abs(motion_sensor.tilt_angles()[0]) > QUARTER)
        motor_pair.stop(motor_pair.PAIR_1)


runloop.run(main())
