More builds, in Word Blocks

Two more LEGO models, each with five short programs in Word Blocks, the coloured blocks in the SPIKE App. Use them on a day the class builds something new, or for a team that finishes early.

The Game Master

The Game Master is a machine for a memory game. You push a candy stick into it: a row of five LEGO bricks in different colours. Motor A moves the candy stick along, one brick at a time, and the colour sensor in port B measures the colour of the brick above it.

The Grabbers

The Grabbers are a hand controller and two different claws. You hold the controller and squeeze its force sensor, in port E. Motor A closes and opens the claw. Each claw is built for different things: one has a bendy claw and one has a split claw.

How a session runs

Robot check, then opener

A week passes between sessions. Each session starts by checking the robot against the robot page, then brings back last week's ideas with a few questions.

Predict, then run

Each chunk shows a program and where the robot starts. You say what the robot will do. Then you run the program and check.

One change per run

When you test, change one thing, run the program, and write down what the robot did. Then you know what that one change does.

Three places to stop

Every mission has a floor, a middle, and a stretch exit. All three are a finish.
