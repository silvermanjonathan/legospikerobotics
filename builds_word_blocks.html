Word Block snippets: Game Master and Grabbers

Two more LEGO models, five short block programs each.

These are Word Blocks, not Python

Every program on this page is made of Word Blocks, the coloured blocks in the SPIKE App. Start a new Word Blocks project, not a Python project, and drag in the blocks in the same order, from the top down.

Each block has the colour of its group in the app. Blocks inside a C-shaped block, such as repeat or if, sit inside its arm, and run only when that block says so.

Each snippet has a question. Say your answer to your partner, run the program, then open the answer.

The Game Master

The Game Master is a machine for a memory game. You push a candy stick into it: a row of five LEGO bricks in different colours. Motor A moves the candy stick along, one brick at a time, and the colour sensor in port B measures the colour of the brick above it.

Every snippet here starts by moving the candy stick to its start. Then it turns motor A by 95 degrees of motor turn to move the stick on by one brick. LEGO's own program for this model uses the same two moves.

The Game Master · snippet 1 of 5

Get the candy stick ready

This is the start of every Game Master program on this page.

Setup: a candy stick is pushed into the Game Master.

Predict: Which happens first, the motor or the sound? Does the sound start while the motor is still turning?

The motor turns first, then the sound plays.

No. A run for block finishes before the block under it starts, so the sound waits until the motor has turned for 2.1 seconds.

The Game Master · snippet 2 of 5

Is this brick red?

The six-sided block asks a question that is true or false. The if block runs the blocks in its top part when the answer is true, and the blocks in its else part when the answer is false. It never runs both.

Setup: hold one brick over the colour sensor, then run the program. Try a red brick, then a blue one.

Predict: Which sound plays for the red brick? Which sound plays for the blue brick?

Red brick: Win. The answer to the question is true, so the top part runs.

Blue brick: Oops. The answer is false, so the else part runs.

The Game Master · snippet 3 of 5

Read all five bricks

The repeat block runs the blocks inside it 5 times: one time for each brick. Each time, it checks the brick, then moves the candy stick on by one brick, then waits 1 second.

Setup: a candy stick with red bricks in places 2 and 4. Place 1 is the first brick the colour sensor measures.

Predict: How many beeps do you hear? How many times does motor A turn by 95 degrees of motor turn?

2 beeps, one for each red brick. The beep plays only when the answer to the question is true.

5 times. The motor block is inside the repeat block but not inside the if block, so it runs every time round, red or not.

The Game Master · snippet 4 of 5

Which place is the red brick in?

A variable is a name that holds a number. This program counts the places in a variable called spot. It starts at 0 and goes up by 1 for each brick. When the brick is red, the light matrix shows spot.

Setup: a candy stick with one red brick, in place 3.

Predict: What number does the light matrix show?

3. spot goes up by 1 before each brick is checked, so it is 1 for the first brick, 2 for the second, and 3 for the third. The third brick is red, so the light matrix shows 3.

The Game Master · snippet 5 of 5

Count the red bricks

This time the variable counts red bricks, not places. It goes up only inside the if block. The write block is outside the repeat block, so it runs once, at the end.

Setup: a candy stick with red bricks in places 1, 2, and 5.

Predict: What number does the light matrix show, and when does it show it?

3, and only after all five bricks have been read. The write block is under the repeat block, not inside it.

The Game Master · your turn

Player 2 guesses the place of the red brick, from 1 to 5, and writes the guess down. Then run the program from snippet 4. A right guess wins a point. Swap and play again.

The Grabbers

The Grabbers are a hand controller and two different claws. You hold the controller and squeeze its force sensor, in port E. Motor A closes and opens the claw. Each claw is built for different things: one has a bendy claw and one has a split claw.

In these snippets, motor A turning counterclockwise closes the claw and clockwise opens it. LEGO's own program for this model turns it the same way.

The Grabbers · snippet 1 of 5

Close, then open

This program does not use the force sensor. It is a test that the claw works.

Setup: the claw is open and holds nothing.

Predict: Does the claw close first or open first? How long is it shut before it opens?

It closes first. The first motor block turns counterclockwise.

About 1 second. The wait block sits between the two motor blocks.

The Grabbers · snippet 2 of 5

Squeeze to grab

The wait until block waits until its question is true. The start motor block starts the motor and does not stop it. The claw keeps closing, and then holds, until another motor block runs.

Setup: run the program, then squeeze the force sensor and hold it.

Predict: What does the claw do while you keep squeezing? What happens when you let go?

It closes and keeps pushing closed, so it holds what it grabbed.

It opens. Letting go makes the second wait until block's question true, and the last block turns the motor clockwise for 0.5 seconds.

The Grabbers · snippet 3 of 5

Grab five times

The repeat block runs the four blocks inside it 5 times: five grabs.

Setup: run the program, then squeeze and let go six times.

Predict: What happens on the sixth squeeze?

Nothing. The repeat block ran 5 times and the program ended. Run it again for five more grabs.

The Grabbers · snippet 4 of 5

Count the grabs

The variable grabs holds the number of grabs so far. The light matrix shows it after every squeeze.

Setup: run the program, then squeeze and let go three times.

Predict: What number is on the light matrix after the third squeeze? What number does it show first?

3 after the third squeeze.

1 first. grabs starts at 0, but it goes up by 1 before the write block runs, so the first number shown is 1.

The Grabbers · snippet 5 of 5

A slower grab

The set speed block changes how fast motor A turns in every motor block under it. This program is snippet 2 with that one block added.

Setup: run it next to snippet 2 on another team's grabber, and squeeze both at once.

Predict: Which claw closes faster? Does the slow claw open as wide as the fast one?

The claw running snippet 2 closes faster.

No. Both open for 0.5 seconds, and the slow motor turns less far in the same time, so the slow claw opens less wide. Try a longer time in the last block, one change per run.

The Grabbers · your turn

Fair test: which claw grabs it?

Run a fair test of the two claws, as LEGO's lesson does. Use snippet 2 on both, the same objects, and the same person squeezing. Change only the claw.

Try things of different sizes that weigh about the same, then things of about the same size that weigh different amounts.

Teacher panel

Before class

  • Both models are built from the SPIKE Prime set. LEGO's lessons for them list the SPIKE Prime set only.
  • Build one of each model yourself and run every snippet on it before the class does. These snippets have not been run on a hub yet.
  • On the Grabbers, check that counterclockwise closes the claw. If it opens it, swap the two arrows in every Grabbers snippet.
  • In the SPIKE App, check that the force sensor's question block offers released as well as pressed. If it does not, use LEGO's two-stack version from its lesson.
  • On the Game Master, check that 95 degrees of motor turn moves the candy stick on by exactly one brick, and that 2.1 seconds brings it to the first brick.

Where each fact on this page comes from

  • Ports, the 2.1 seconds, the 95 degrees of motor turn, the motor directions, the sound names, and the block words: LEGO's own block programs on its lesson pages for these two models, read on 12 November 2026.
  • The snippets: written for this course. LEGO's lesson for the Game Master uses lists and broadcast messages, which this course never uses, so snippet 4 finds the place of the red brick with a counter instead.
  • LEGO labels both lessons grades 6 to 8. It rates the Grabbers lesson Beginner, 30 to 45 minutes, and the Game Master lesson Intermediate, 45 to 90 minutes.
