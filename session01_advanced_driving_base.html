Build · 45 minutes

Build the Advanced Driving Base

Today your team of four builds one robot. LEGO calls it the Advanced Driving Base. A driving base is a robot with two wheels, and each wheel is turned by its own motor.

The robot is built in four parts. Each builder makes one part from one building book. Then the whole team joins the four parts with a fifth book.

The hub is the box with the buttons and the square of lights. It holds the program and runs it. A port is one of the six sockets on the hub. The ports are lettered A to F, and each cable plugs into one port. A motor turns something. A sensor measures something.

Chunk 1 of 3

Pair the motors, then move forward

A program is a list of lines. The hub runs the lines in order, from the top down. Lines 1 to 3 bring in the tools this program uses. Line 8 tells the hub which two motors turn the wheels: the left motor is in port A and the right motor is in port E. Line 11 turns the wheels.

The first number on line 11 says how far the motors turn. It is counted in degrees of motor turn. 360 degrees of motor turn is one full turn of the wheel, and one full turn of this wheel moves the robot about 28 cm.

from hub import port
import motor_pair
import runloop


async def main():
    # The left drive motor is in port A. The right drive motor is in port E.
    motor_pair.pair(motor_pair.PAIR_1, port.A, port.E)

    # Move forward. The wheels turn 720 degrees of motor turn.
    await motor_pair.move_for_degrees(motor_pair.PAIR_1, 720, 0, velocity=250)


runloop.run(main())

The parts of line 11

PartWhat it says
motor_pair.PAIR_1The two drive motors that line 8 paired.
720How far the motors turn, in degrees of motor turn.
0The steering. 0 means straight.
velocity=250The speed. The motors turn 250 degrees of motor turn each second.

Predict: Look at line 11. Which way does the robot move, forward or backward? About how many cm does it move, to the nearest 5?

720 is 360 + 360. How many full turns of the wheel is that?

One full turn of the wheel moves the robot about 28 cm. Add that up for each full turn.

What the page works out

Computed, not measured

2 full turns of the wheel
28 cm + 28 cm = 56 cm
to the nearest 5: 55 cm

The first one: forward. The first number on line 11 is 720, with no minus sign.

The second one: about 55 cm. 720 degrees of motor turn is 2 full turns of the wheel, because 360 + 360 = 720. Each full turn moves the robot about 28 cm, and 28 + 28 = 56. To the nearest 5, that is 55 cm.

Now measure your own run. Lay a ruler from the start line to the robot's front edge and write the number down. Your number may differ from 55 by a little. If it differs by a lot, go back to the robot check list.

Chunk 2 of 3

A minus sign moves the robot backward

Each move line starts with await. await makes the hub finish that move before it starts the next line. So two move lines give two moves, one after the other.

A minus sign in front of the first number turns the wheels the other way. The robot moves backward.

from hub import port
import motor_pair
import runloop


async def main():
    # The left drive motor is in port A. The right drive motor is in port E.
    motor_pair.pair(motor_pair.PAIR_1, port.A, port.E)

    # Move forward. The wheels turn 720 degrees of motor turn.
    await motor_pair.move_for_degrees(motor_pair.PAIR_1, 720, 0, velocity=250)


runloop.run(main())

Line 14. What goes next? Line 11 has moved the robot forward. Line 14 moves it backward by the same number of degrees of motor turn. What is line 14?

Line 14 uses the same function as line 11.

Only the first number is different from line 11.

Chunk 3 of 3

Steering turns the robot

The second number in a move line is the steering. With steering 0, both wheels turn the same way and the robot moves straight.

With steering 100, the left wheel turns forward and the right wheel turns backward. The robot stays on its spot and turns to its right. A minus sign on the steering swaps the two wheels.

from hub import port
import motor_pair
import runloop


async def main():
    # The left drive motor is in port A. The right drive motor is in port E.
    motor_pair.pair(motor_pair.PAIR_1, port.A, port.E)

    # Turn on the spot. The steering is -100.
    await motor_pair.move_for_degrees(motor_pair.PAIR_1, 360, -100, velocity=250)


runloop.run(main())

Hinge question · from today's chunks

Mission · 10 minutes

Out, around, and home

Your robot is a delivery cart in a warehouse. It drives out to the far line, turns to face home, and drives back. A cart that stops out in the aisle is in the way of the next cart, so the wheels must end where they started.

You already know how far to drive. You do not yet know what number makes the robot turn half way round, so that it faces home. You will find it by testing: change one number, run, and write down what the robot did.

from hub import port
import motor_pair
import runloop


async def main():
    # The left drive motor is in port A. The right drive motor is in port E.

    # Move forward. The wheels turn 720 degrees of motor turn.

runloop.run(main())
