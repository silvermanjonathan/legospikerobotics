What do you remember from sessions 1 to 4?

Talk each question through with your team before you open its answer. Your ledger card can help.

Question: Three lines move the robot until a line of tape. What does each one do?

The first starts the wheels. The second waits until the reflected light is less than DARK. The third stops the wheels.

Question: Some lines start with await and some do not. What is the difference?

A line with await makes the hub finish that job before the next line starts. A line without it only starts the job, and the hub goes straight on.

Question: What does for count in range(4): do?

It runs the lines inside it 4 times.

Question: Why does each team have its own number for DARK?

Each team measured its own floor and its own tape. The number has to sit between those two readings.

Chunk 1 of 3

The hub can show and beep

Line 6 shows the text inside the quote marks on the light matrix, the square of 25 lights on the hub. Lines 7 and 8 each play one note.

A beep has three numbers. The first is the pitch: a bigger number is a higher note. The second is how long the note lasts, counted in thousandths of a second, so 500 is half a second. The third is how loud, from 0 to 100.

from hub import light_matrix, sound
import runloop


async def main():
    light_matrix.write("3")
    await sound.beep(440, 500, 100)
    await sound.beep(880, 500, 100)


runloop.run(main())

Chunk 2 of 3

Cross one line and stop after it

Line 16 is the wait you know: it waits until the reflected light is less than DARK, which happens when the sensor reaches the tape.

Line 17 is new. The sign > means "is greater than". Line 17 waits until the reflected light is greater than DARK again, which happens when the sensor has left the tape.

from hub import port
import color_sensor
import motor_pair
import runloop

LINE_SENSOR = port.B
DARK = 50


async def main():
    # The left drive motor is in port A. The right drive motor is in port E.
    motor_pair.pair(motor_pair.PAIR_1, port.A, port.E)

    # Start the wheels. Wait for the tape, then wait for the floor again. Stop.
    motor_pair.move(motor_pair.PAIR_1, 0, velocity=250)
    await runloop.until(lambda: color_sensor.reflection(LINE_SENSOR) < DARK)
    await runloop.until(lambda: color_sensor.reflection(LINE_SENSOR) > DARK)
    motor_pair.stop(motor_pair.PAIR_1)


runloop.run(main())

Chunk 3 of 3

Count the lines

Line 8 names the shelf to stop after. The for line on line 17 runs the four lines inside it once for each shelf line: wait for the tape, show a number, beep, wait for the floor.

Each time round, count holds a number. Line 19 turns that number into text with str, because the light matrix shows text. Lines 19 and 20 have no await, so the robot keeps moving while the hub shows and beeps.

from hub import light_matrix, port, sound
import color_sensor
import motor_pair
import runloop

LINE_SENSOR = port.B
DARK = 50
SHELF = 3


async def main():
    # The left drive motor is in port A. The right drive motor is in port E.
    motor_pair.pair(motor_pair.PAIR_1, port.A, port.E)

    # Start the wheels. Count the lines. Stop after the last one.
    motor_pair.move(motor_pair.PAIR_1, 0, velocity=250)
    for count in range(SHELF):
        await runloop.until(lambda: color_sensor.reflection(LINE_SENSOR) < DARK)
        light_matrix.write(str(count))
        sound.beep(440, 200, 100)
        await runloop.until(lambda: color_sensor.reflection(LINE_SENSOR) > DARK)
    motor_pair.stop(motor_pair.PAIR_1)


runloop.run(main())

Lines 18 to 21 are inside the for line, eight spaces in. Line 22 is back at four spaces, so it runs once, after the last line has been counted.
